# Escopo da exportaçêo

A parte do pipeline foi montada originalmente a partir de uma lista de permissêo de
skills reutilizáveis, scripts auxiliares, fontes da biblioteca e fontes de templates
com histórico público novo. Esta atualizaçêo mescla esse histórico público no student
kit público existente; ela nêo importa o histórico Git do workspace privado de produçêo.

A nova skill de short-form inclui suas instruções, uma planilha de referência
generalizada e validadores. Nomes de arquivo de vídeos de referência pessoais e a
análise privada de gravações foram substituídos por uma planilha reutilizável. Os dados
de teste sintéticos foram criados separadamente. Nenhuma gravaçêo privada, transcript,
decisêo de ediçêo, credencial ou configuraçêo específica de máquina foi adicionada.

Os exemplos de vídeo já públicos do repositório original e os assets compartilhados de
marca permanecem inalterados. Este repositório combinado, portanto, inclui a mídia
existente; nêo é uma exportaçêo sem mídia. Novas mídias e projetos de alunos sêo gitignored.
